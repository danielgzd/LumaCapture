# LumaCapture 产品需求文档

版本：0.1.2 · 2026-09-09 · 状态：已实施

## 1. 产品目标

为 Apple Silicon（M 系列）与 Intel Mac 提供原生、离线、轻量的截图与录屏工具。主要用户为开发者、设计师、文档作者及需要日常分享屏幕内容的用户。采用 SwiftUI / AppKit，系统媒体框架，无第三方运行时和云端依赖。中文界面。

交付物：需求文档、任务清单、完整源码、自动化测试、验收记录、Universal 2 `.app`、ZIP、DMG、SHA-256 校验文件、GitHub 源码及 Release 附件。

## 2. 支持范围

- macOS 15.0 及以上；同一可执行文件包含 arm64、x86_64。Intel Mac 本身须支持该系统。
- 多显示器、Retina 坐标转换；区域选择限定在一个显示器内，支持负坐标显示器。
- 本机为 Apple Silicon，Intel 交叉编译和二进制检查必做；若 Rosetta 可用则增加 x86_64 测试。未拥有的 Intel 实机不得声称已验证。
- 首次屏幕录制、麦克风访问按系统权限提示操作；拒绝时解释如何恢复，不崩溃、不伪造成功。

## 5. 交互流程

截图：选择目标 → 可选延迟 → 隐藏控制台 → 选择区域（如适用）→ 捕获 → 保存原图并添加历史 → 打开编辑器 → 标注/OCR/贴图/复制/另存。

录屏：选择目标与音频/帧率 → 权限检查 → 可选倒计时 → 录制状态与时长 → 停止 → 等待媒体封装 → 历史及 Finder。开始/停止之间禁用冲突操作。

默认目录：用户桌面。截图与录屏使用同一可编辑目录；默认无网络请求，不上传用户截图和录屏。

## 6. 非功能要求

- 保持主线程可交互，捕获和文件写入使用异步系统 API。
- 大尺寸 Retina 截图的 PNG 压缩不得阻塞编辑器出现；拖动标注期间不得反复编码或写入完整图像。
- 编辑器预览应控制显示内存与重复渲染成本；保存、复制、OCR 使用同一份全分辨率编辑结果。
- 录像只向磁盘流式写入，不累积完整视频到内存。
- 错误包括可执行恢复建议，不能静默吞掉捕获/导出失败。
- 快捷键使用系统注册 API，避免要求额外辅助功能权限。
- 编辑预览和导出共享坐标与变换逻辑；隐私遮挡写入不可逆马赛克像素。
- 所有保存路径均通过 URL/FileManager，避免拼接 shell 命令处理用户路径。
- 无跟踪、广告、账户系统或自动网络上传。

## 7. 明确的后续迭代

自动滚动长截图、录像暂停续录、GIF 导出、摄像头叠加、视频裁剪/背景美化、云分享、自动更新作为后续版本；首版 UI 不提供不可用的占位按钮。

## 8. 发布与验收边界

采用本地 ad-hoc 签名作为可构建的基线。Developer ID 签名和 Apple 公证依赖用户持有证书/开发者账户；检测到本机没有可用签名身份时，不宣称已公证。下载后的系统信任流程在 README 说明。

GitHub 发布：使用已认证账号 `danielgzd` 创建公开仓库 `danielgzd/LumaCapture`，代码采用标准 MIT License，并通过 Release 提供 Universal 2 安装包和校验文件。

完成定义：每个首版需求有对应实现、自动化或实际验收证据；未验证的真实屏幕/音频/硬件场景明确标记，不把编译成功当成功能通过。
