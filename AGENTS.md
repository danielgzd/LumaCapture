# Working rules

Read docs/REQUIREMENTS.md and docs/TASKS.md before implementation. Native Swift/SwiftUI/AppKit, macOS 15+, Swift 5 mode. No third-party runtime dependencies. Work within assigned module boundaries; coordinate API changes with primary agent. Never claim unexecuted checks passed. Do not commit generated captures containing user screen content. Build with scripts/build.sh; core tests with scripts/test.sh. Sources must compile for arm64 and x86_64. Do not use force unwraps for fallible media operations. Code and documentation are primarily Chinese-facing, identifiers in English.
